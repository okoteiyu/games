# おこていゆゲームズ

のんびり暮らす自称研究者「おこていゆ」を、そっと見守るゲームです。家で過ごし、ときにはちょっかいをかけながら、おこていゆの怒りから新しい技や力を発見します。パトロールでは、妖精に道をお願いしたり、かけごえでオートバトルを応援したりできます。

- [トップページ](https://okoteiyu.github.io/games/)
- [ゲームで遊ぶ](https://okoteiyu.github.io/games/game/)
- [攻略サイト](https://okoteiyu.github.io/games/guide/)

Web版はベータ版かつLite版です。3Dの暮らし・パトロール・戦闘・コレクションをブラウザで体験できます。ストーリーやヒーロー会サービスは含まれません。iOS版、その後Android版を予定しています。

開発中のゲームのベータ版を公開するサイトです。黄緑と薄い茶色を基調にした攻略サイトでは、おこていゆのプロフィールや仲間たち、遊び方、珍生物・もちもの・技の特徴に加え、穏やかポイントの使いみち・獲得方法と、おこていゆイベントの入手候補を紹介しています。

著作者：**okoteiyu**

## 遊び方

ゲームを開き、初回の案内を確認してください。新しく始める場合は、おこていゆのレベル5・穏やかポイント10でスタートします。攻略サイトの初期セーブデータも同じ状態です。操作方法は攻略サイトから確認できます。進行はブラウザに自動保存され、ゲーム内のオプションから暗号化したセーブファイルを読み書きできます。端末・ブラウザを変える前には、セーブを書き出しておくと安心です。ファイルを読み込む前に、おこていゆのレベル、所持品の数と内訳、記録帳の登録数を確認できます。

## 実行・公開

対応ブラウザのJavaScriptとWebGLを有効にして遊んでください。初回は3Dデータの読み込みに時間がかかります。

ローカルでは `python3 -m http.server 8000 --directory site` を実行して `http://localhost:8000/` を開きます。公開開始後は、`main` へのpushでGitHub Actionsが公開ファイルを検証し、`site/` から配信用ファイルをビルドしてGitHub Pagesへ配信します。
